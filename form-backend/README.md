# 登記表單的後端設定

這份說明是給專案維護者看的。一般使用者不需要做這些事。

登記頁面是 `docs/index.html`，一個不需要伺服器的靜態網頁。資料送到一支 Google Apps Script，由它寫進你的 Google 試算表，上傳的申請書則存進你的 Google 雲端硬碟。

## 為什麼不是直接用 Google 表單

Google 表單不接受從自訂網頁送來的檔案上傳，而且使用者上傳檔案時必須先登入 Google。改用試算表加 Apps Script，資料一樣落在你的 Google 帳號裡，可以收檔案，使用者也不用登入。

如果你不需要自訂頁面，最省事的做法是直接開一張 Google 表單，把「貼給 AI 助理的指令」和專案連結寫在表單的「確認訊息」裡。

## 設定步驟

1. 建立一份新的 Google 試算表，名稱自訂。
2. 選單「擴充功能」→「Apps Script」，把編輯器裡的內容全部換成本資料夾的 `Code.gs`，存檔。
3. 上方函式選單選 `setup`，按「執行」。第一次會要求授權，同意後它會建立「登記」工作表，以及雲端硬碟裡的「青年百億申請幫手_上傳的申請書」資料夾。
4. 右上角「部署」→「新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：所有人
5. 部署後複製「網頁應用程式網址」（結尾是 `/exec`）。
6. 打開 `docs/index.html`，把最下方 `CONFIG` 的 `ENDPOINT` 換成剛才的網址。再打開 `docs/privacy.html`，把聯絡信箱與資料用途改成你自己的，中英文兩段都要改，內容必須與你實際的做法一致。登記頁面核取方塊上方的那一句重點摘要也要同步。
7. 到 GitHub repo 的 Settings → Pages，Source 選「Deploy from a branch」，分支選 `main`、資料夾選 `/docs`。幾分鐘後頁面會出現在 `https://<你的帳號>.github.io/<repo 名稱>/`。

之後修改 `Code.gs` 時，要到「部署」→「管理部署作業」建立新版本，網址才會套用新的程式。

## 測試

`ENDPOINT` 留空時頁面是預覽模式，可以走完流程但不會送出資料。填入網址後，自己送一筆測試資料，確認試算表多了一列、雲端硬碟多了檔案。

## 你蒐集了個人資料，這幾件事要做到

- `docs/privacy.html` 的資料使用說明必須寫出真實的用途。之後要增加用途，要先更新說明，並取得已登記者的同意。
- 提供可用的聯絡信箱，有人要求查詢、更正或刪除時要處理，包含刪除雲端硬碟裡他上傳的檔案。
- 試算表與資料夾不要分享給不需要看的人，也不要設成「知道連結的人都能檢視」。
- 未滿 18 歲的使用者需要法定代理人同意。頁面會在出生年推算未滿 18 歲時要求勾選，這只是自我聲明。
- 網頁應用程式的網址是公開的，任何人都能對它送資料。`Code.gs` 有基本的防護（隱藏欄位、長度限制、檔案類型與大小限制、防止試算表公式注入），但擋不住刻意的灌水。發現異常時，到「管理部署作業」停用該部署即可。
