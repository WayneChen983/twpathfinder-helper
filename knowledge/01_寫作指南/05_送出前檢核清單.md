# 10 送出前檢核清單

可直接複製給申請者自我檢查。

## 格式
- [ ] A4 直式、15–30 頁（不含附件表單）
- [ ] 固定行高 24 點、標楷體、18／16／14 號字
- [ ] 每頁有頁碼
- [ ] PDF、10MB 以內
- [ ] 封面計畫編號、名稱、日期正確
- [ ] 經費同意欄已勾選

## 結構
- [ ] 有一頁摘要或開場「選擇我的理由」
- [ ] 學經歷開頭有一頁式簡表，數字化
- [ ] 簡章列出的每一個見習機構都有寫
- [ ] 每個機構都寫了「希望得到的收穫」並連到自己的背景
- [ ] 行程中與自己最相關的活動有點名
- [ ] 動機段有明確寫出「我缺什麼、計畫能補什麼」
- [ ] 有「為什麼是我」或等同的段落
- [ ] 回國規劃分短中長期，短期有數字目標，長期有實質作為

## 內容品質
- [ ] 大標題、小標題都盡量量化
- [ ] 每段經歷有：做了什麼、數字成果、學到什麼、連回計畫
- [ ] 有至少一個具體案例證明做過功課
- [ ] 所有數字前後一致（表格、內文、摘要）
- [ ] 所有機構資料、案例、統計都查證過來源
- [ ] 沒有通用的產業介紹佔篇幅
- [ ] 刪除測試：每段拿掉後評審都會少知道某件事

## 版面
- [ ] 沒有連續兩頁以上純文字
- [ ] 所有【佐證照片】佔位已補上
- [ ] 證書集中在最後，有標題
- [ ] 英語證明：有檢定放檢定；沒有則用照片＋說明證明溝通能力；簡章列為優先條件時一定要附

## 最後
- [ ] 錯字、重複字、斷字檢查
- [ ] 請一位沒看過的人讀一頁摘要，問他「這個人缺什麼、要去做什麼」，答得出來才算過
- [ ] 準備中英文版與 3 分鐘簡報（面試用）

## 換位自測
- [ ] 用 2 分鐘快速翻完整份，能不能抓到重點？
- [ ] 用「政府機關」的視角看一次（這筆錢花在你身上，台灣能得到什麼？）
- [ ] 用「合作機構」的視角看一次（你來了能不能融入、能不能貢獻？）
- [ ] 每一段都能回答「這段跟計畫的關聯是什麼？」
- [ ] 需要推薦信的話，已提早聯繫推薦人
