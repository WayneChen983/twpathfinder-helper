# 02 常見問題標準回覆

每題附「重點」與「可直接貼的回覆」。回覆用你的口吻，可依對方情況刪減。

---
## Q1 企劃書要寫幾頁？比重怎麼分？
重點：寫滿 30 頁；學經歷 1/2、了解＋動機＋期待＋回國 1/3、補充 1/6；學經歷是門檻，動機是關鍵。
```
我是寫滿30頁
1/2 學經歷
1/3 動機 對計畫的了解 期待的收穫
1/6 放一些補充的 我覺得可以加分的東西

學經歷篇幅最多 是因為它是門檻
門檻過了評審才會再考慮你
但真正決定錄取的 是動機、對計畫的了解、期待的收穫
```

## Q2 一定要寫到什麼？
```
釐清你的弱點
以及
你都這麼厲害了
為什麼還需要參加這個計畫
你期待這個計畫補足你什麼地方
讓你有什麼樣的收獲

讓評審覺得你很強 你是準備好的
同時又要透露你不足的地方
「最後一塊拼圖🧩」
```

## Q3 「不足」要寫什麼？困難嗎？
```
不一定是困難 也可以是你缺少的
1.經濟能力 這個計畫會給你們錢
2.你不知道怎麼跟海外單位連結 但這個計畫會幫你們跟那邊的人牽線
3.想透過這個計畫認識同行的人等
```

## Q4 回國後計畫要寫多具體？期待跟回國計畫重疊可以嗎？
```
當然沒問題

我是這麼陳述的：
短期計劃就是發文 發影片 或是跟人分享所見所聞
長期計畫偏向是把技術帶到產業 或是建立台美的橋樑等

長期計畫是不確定性極高的 不用那麼具體

大部分的人只寫回來分享
但業師會比較希望看到更多實質的作為
```

## Q5 機構很多（例如八個），要每個都寫嗎？會不會佔太多篇幅？
```
如果有八個機構
我會建議每個都寫
然後每個都寫下你希望在這些機構有什麼樣的收獲

佔篇幅沒關係
對計畫的了解跟期待的收穫本來就是錄取的關鍵

小技巧是
每個機構的介紹 直接接你希望在那裡得到什麼
這樣「了解」跟「期待」一次寫到

每個機構半頁左右就夠
頁數爆了就從學經歷精簡
```

## Q6 要不要放圖？可以放 AI 做的圖嗎？可以加顏色嗎？
```
我的圖都有點放不完了哈哈
放你參加活動的照片就好
單純不要讓版面都是文字

文字加顏色應該沒關係
```

## Q7 標題量化是什麼意思？
```
把數字放到標題上
例如
「擔任志工講師」→「44 堂課、教 520 人次長輩用手機」
「參加黑客松」→「48 小時、37 隊中拿下第二名」
評審翻過去只看標題也能抓到重點
```
（作者自己的標題例子：把校園文化變成 50 萬營收、從 204 組中奪冠）

## Q8 目錄要放嗎？其他證明文件放什麼？要不要作品集連結？
```
我沒有另外放目錄頁 架構照簡章的題目走
有人放目錄也很好 兩種都可以

我的做法是
內文放活動照片
其他證明文件集中放獎狀、證書、獲獎公告
用表格一格一張 下面寫一行標題
大概佔2頁

作品集連結我沒有另外放
評審不一定會點
重要的東西要直接放在企劃書裡
```

## Q9 英檢要放嗎？
- G-3-4 類（非必要）：
```
英檢非必要
如果分數不是特別突出 甚至其他人都金證 反而是弱勢
可以不要放
放你國外交流或跟外國人交流的照片就好
```
- 簡章列為優先條件的計畫（例如 M-9-5 要 CEFR B1 以上並附證明）：
```
這個計畫簡章優先條件有英檢 B1
有的話一定要放
```

## Q10 經歷很豐富／有很多海外經驗，要怎麼寫？
```
海外經歷你可以不要揭露
因為就我對這個計畫的業師的了解
他比較想把機會給「不足」的人
而不是給已經有資源的人

如果你要揭露的話
確實可以說你經歷豐富
那你就要說「你缺的拼圖是什麼」
```

## Q11 我不想過度包裝，想誠心分享，可以嗎？
```
誠心很好 這是最基本的
但包裝不是造假
是把你有的寫得更突出
例如多量化 多一點「數字」
同時把你沒有的、需要透過這個計畫得到的 也清楚寫出來
```

## Q12 主辦單位／評審在找什麼樣的人？
```
不一定是最厲害的人
而是
已經準備好、門檻有過
但還缺「最後一塊拼圖🧩」
這個計畫剛好能幫你補上的人

再來是回國後能帶來實質貢獻的人
大部分的人只寫回來分享
但他們更希望你把學到的東西帶回台灣
```

## Q17 申請書要怎麼開始寫？架構是什麼？
```
照簡章的題目走就好
1.學經歷
2.對計畫跟機構的了解
3.動機跟期待
4.回國後計畫
5.經費（勾同意就好）
6.外語證明
7.其他證明文件

開頭可以先放一頁重點摘要
讓評審一頁就知道你是誰、缺什麼、要去幹嘛
```

## 審閱申請書時的固定流程
1. 先讀簡章：見習機構數量、每日行程、行前培訓、優先條件（英檢等）。
2. 對照申請書：機構是否都寫到、行程中最符合對方背景的活動是否點名。
3. 找缺口段落：有沒有寫「缺什麼」、放在哪裡。
4. 找一個最好的地方先肯定。
5. 只挑 2–3 個最重要的建議回覆；錯字與細節等第二版。
6. 用 01_寫作指南/05_送出前檢核清單 做最後檢查。

## Q18 我不知道要選哪個計畫？
```
把有興趣的簡章都看過
問自己三題
跟我背景最扣合？
對我未來幫助最大？
最讓我心動？
三個的交集就是最適合你的

想提高錄取率就選最扣合背景的
想轉換跑道也可以
但要寫出很強的動機 跟你有相關潛力的例子
```

## Q19 評審是怎麼打分數的？
```
簡章的書審標準大概是
學經歷跟計畫的相符程度 40%
申請動機 20%
預期效益跟未來發展性 40%
（以你那期簡章為準）

所以經歷不是越多越好 是要跟計畫相關
回國後的規劃也很重要 要具體 可以做得到
```

## Q20 我覺得自己還不夠厲害，要投嗎？
```
先投再說
沒有百分之百準備好的時候
```
