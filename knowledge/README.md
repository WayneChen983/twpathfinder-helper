# 知識庫

這裡是 AI 助理撰寫與審查申請書時參考的資料。內容是作者的個人經驗與整理，不是官方說法；計畫的事實請以 `data/kb/` 的簡章與官網為準。

| 資料夾 | 內容 |
|---|---|
| `01_寫作指南/` | 審查邏輯、格式與篇幅、各章寫法、版面句型與常見錯誤、送出前檢核清單 |
| `02_範例拆解/` | 作者本人錄取 G-3-4 常春藤 AI 領袖培訓營的申請書拆解 |
| `03_諮詢話術/` | 常見問題的回答與回覆口吻 |
| `05_計畫與經驗資料/` | 錄取經驗、時程與面試形式、公開經驗分享的重點整理 |

為了保護其他申請者，公開版本不包含任何人的申請書全文，也不包含可辨識個人的經歷細節。文中的例子來自作者本人，或 `examples/` 裡的虛構申請者。
