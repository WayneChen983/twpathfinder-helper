青年百億申請幫手

找到適合你的圓夢計畫，把申請書寫出來

在你自己的 Claude Code 或 Codex 裡，找計畫、寫申請書、輸出符合簡章格式的 Word 檔。先登記，送出後就會看到使用方式。

怎麼運作

  1. 1填寫下面的表單並送出。
  2. 2畫面會出現一段指令和專案連結。
  3. 3把指令貼給你的 AI 助理，它會帶你完成之後的每一步。

基本資料

學經歷與背景

寫得越具體越好：做了什麼、你的角色、有什麼數字。這些內容之後可以直接下載成背景檔，交給 AI 助理使用。

初版申請書

PDF 或 Word，10 MB 以內。請先移除身分證字號、地址等不需要的個資。PDF 太大的話，可以先到 iLovePDF 壓縮（第三方網站）。

Privacy Notice

送出前請先閱讀 Privacy Notice（資料使用說明）。

傳送中，請稍候…

登記完成，接下來這樣做

  1. 1在電腦上開啟 Claude Code 或 Codex。還沒安裝的話，先依官方說明安裝其中一個。
  2. 2把下面這段指令整段複製，貼給它。
  3. 3照它的引導一步一步做。你的資料會留在自己的電腦上。

貼給 AI 助理的指令

指令後半段已經帶入你剛才填的學經歷與背景，AI 助理會直接用它建立你的背景檔，不用重新輸入。裡面不含姓名、電話和 Email。
